# 📚 Blog Técnico: Arquitectura de Software

**Autor:** Yun Erasmo Martinez

Un blog profesional y visualmente atractivo sobre Arquitectura de Software, desarrollado con HTML, CSS y JavaScript vanilla.

## 🎯 Objetivo del Proyecto

Este proyecto es resultado de una investigación académica completa sobre Arquitectura de Software. El objetivo es crear un recurso educativo completo que abarque:

- Fundamentos de la Arquitectura de Software
- Estilos Arquitectónicos más utilizados
- Patrones Arquitectónicos Modernos

## 📖 Contenido del Blog

### POST 1: ¿Qué es la Arquitectura de Software?
Explora los fundamentos de la arquitectura, incluyendo:
- Definición conceptual
- Objetivos principales
- Componentes básicos (módulos, interfaces, conectores)
- Importancia en escalabilidad, mantenibilidad y rendimiento
- Roles del Arquitecto de Software
- Ejemplos prácticos

### POST 2: Estilos Arquitectónicos Más Utilizados
Análisis detallado de 5 estilos principales:
- **Monolítica**: Estructura simple pero limitada
- **N-Capas**: Separación clara de responsabilidades
- **Cliente-Servidor**: Distribución básica
- **MVC**: Patrón web clásico
- **Microservicios**: Escalabilidad moderna
- Tabla comparativa de características

### POST 3: Patrones Arquitectónicos Modernos
Exploración de patrones avanzados:
- **Clean Architecture**: Independencia de frameworks
- **Hexagonal (Puertos y Adaptadores)**: Máxima flexibilidad
- **CQRS**: Separación lectura-escritura
- Comparación y casos de uso reales
